🟇 CleanBench PSU

My personal power supply unit. This is a 2003 PSU, with new capacitors and some components replaced. It can do up to 20A at 5V, with 3.3V and 12V for a total of 300W.

#reverse engineering #web #api

🟇 Didup Plus

A new and better version of the popular online school platform, used by hundreds pf schools in all of Italy. It features a revamped GUI, vibrant colors, analytics and a better data management system. It uses Argo Proxy, developed by me, that reverse-engineers the API calls that the original platform makes to Argo servers. AI and the possibility to see and download PDFs from the app are coming soon.

#electronics #arduino #python

🟇 D-Desk

ESP-32 based smart desk controller, featuring a 128x64 monochrome OLED display, 9 buttons, 2 potentiometers, a USB-C port for power and endless possibilities. This is a prototype that uses a python listener on the PC to send controls on Internet. One day every mode will be easily customizable via a web tool built for it.
